# 踩的一些坑
- 因为一些历史原因，我在今年初动手改了 git 的 `.config` 文件，加入了一堆 gh-proxy ，它本身没啥问题，关键是我没写好导致整个Git直接烂掉。现在修好了。方法是直接不用gh-proxy了，我有梯子，开Tun模式就行
- 登录时需要 **密码** ，这个密码不是账户密码，而是 **Token** 这种登录凭证，确实要安全很多，配置好持久化之后甚至要比用账户密码更方便
- 上下游要对应好，否则提交的时候Git会因为历史不同，直接不认
- `.git` 目录永远不可以被提交
- 至于用Git的详细情况，就放到我的个人博客去 ~~（还没建完）~~
